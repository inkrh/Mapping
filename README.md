# Mapping

Mapping and Related Data Samples. Kinda old now, but keeping live especially for the climate change docs.

## Interesting

Interesting scraped data from a limited set of news sources for environment and security related keywords. No longer updated. Fetch script ran on a daily basis from 2017 to 2024. 


## Climate Change Docs

Documents (PDFs, PPTs and reports in csv format etc.) on climate change that were publicly available between 2017 and 2020, includes documents initially commissioned and released by the US government and now expunged from US federal and state government websites due to politicization of science, provided to FloodedCity via an old SeedDMS instance.


Also see https://www.flooded.city.



## Geography


*Calculate Prices*

Sample server providing a service price calculator based on ZIP code with a base price plus multiplier.

*FloodedCitySamples*

Sample scripts and scraped data for the Sea Levels application (http://www.flooded.city), includes regularly updated historical data for FEMA and NASA events.

*LocationReporter*

Sample server accepting a location and _x_ quality, returning map tiles spanning the globe with averaged _x_ quality per tile scope.
